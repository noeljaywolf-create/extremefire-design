## Other routes and resources

- `404.html`: error page; excluded from the XML sitemap.
- `thank-you.html`: post-conversion page; excluded from the XML sitemap. The current WhatsApp form handoff does **not** automatically redirect here.
- `robots.txt`: crawler directives and XML sitemap location. `llms.txt`: plain-text business summary.
- `documents/`: downloadable resources linked from the site.
- `/api/chat`: optional Express endpoint, not available on GitHub Pages without a separately deployed backend.

When adding or removing an indexable page, update this inventory, the XML sitemap, internal links and relevant metadata. Confirm the canonical domain before changing URLs.
